# Taking a lapsed client's website offline

When a client's website has ended (the payment is due and unpaid, with no grace period), their website goes offline and comes back when they pay. The rule is `hasWebsiteService` in `packages/billing/src/access.ts`. Plan: `docs/plans/57-site-lapse-hosting-enforcement.md` in the workspace.

Two layers act on that one rule:

| Layer | Where | What a visitor sees | Reacts in |
|---|---|---|---|
| Site | `templates/client-site` `proxy.ts` and `app/layout.tsx` | Our maintenance page, HTTP 503 with `Retry-After` and `noindex` | About a minute |
| Hosting | Hourly sync, `POST /api/internal/sync-site-hosting` | Vercel's own paused page (not ours) | Within the hour; seconds after the client pays |

The site layer only works for sites built from the template. The hosting layer needs nothing from the site, so it also catches a site that never adopted the template.

## Setting up a client

1. The site: copy `proxy.ts`, `lib/offline-check.ts`, `lib/maintenance-response.ts`, `lib/brandbasket.ts` and `components/` from `templates/client-site`, and set `BRANDBASKET_API_ORIGIN` and `BRANDBASKET_SITE_TOKEN` (and optionally `SITE_BUSINESS_NAME`) in the site's Vercel settings. Next 15 and older: name the file `middleware.ts` and the function `middleware`.
2. The console: open the client, Website tab, Vercel project. Paste the project id (Vercel project, Settings, General, Project ID: `prj_...`) and the team id (`team_...`) if the project is on a team. Save. The line under the form says Running, Paused since a date, or the last error.

A site is only paused if the business has a project that reached `live` and the row above exists. Sites without a row are never touched.

## Setting up the server (once)

1. Create a Vercel API token for the Digibranders team and put it in `/srv/brandbasket/shared/platform.env.local` as `VERCEL_API_TOKEN`. `SITE_HOSTING_SYNC_TOKEN` is generated by `scripts/server/make-env-files.sh`; an existing server needs one added by hand (`openssl rand -hex 32`).
2. `deploy/vps/install.sh backups` installs `brandbasket-site-hosting.service` and `.timer`. It does not enable the timer.
3. Read a dry run. It changes nothing:

   ```bash
   runuser -u brandbasket -- /usr/local/sbin/brandbasket-site-hosting-job --env-file /srv/brandbasket/shared/platform.env.local --dry-run
   ```

4. If the list is what you expect, `systemctl enable --now brandbasket-site-hosting.timer`.

## Reading a run

The job prints the report and exits non-zero (so the team gets the failure email) when a person needs to look.

| Answer | Meaning | What to do |
|---|---|---|
| 200 | Done. `items` lists each site paused or unpaused; `held` lists sites left alone and why (`not-launched`, `payment-under-review`, `billing-unreadable`) | Nothing |
| 409 | The brake stopped a batch of pauses: more were due than one run allows (the larger of 3 or 5% of live sites, never more than 10). That many at once usually means a fault, not 11 clients all lapsing | Find the cause (billing outage, bad data). If the lapses are real, pause those projects on Vercel by hand |
| 502 | Vercel refused a change for at least one site. The reason is on the site's row, shown in the console | Fix the project id or token, then wait for the next run or run the job by hand |

A site whose billing cannot be read is never changed in either direction. A payment waiting on staff (`payment-under-review`) is never paused for.

## Bringing a site back by hand

Unpause the project on Vercel. If the client's plan is still lapsed, the next hourly run pauses it again; record their payment (or fix their plan) first. A payment recorded by staff in the console is picked up by the next hourly run, because the console cannot call this app; a payment the client makes themselves, or Razorpay's renewal, unpauses within seconds.

## Known limits

- Pointing a business at a different Vercel project forgets that the old one was paused and leaves it as it was.
- The console cannot clear the project id once saved.
- What Vercel shows on a paused project is Vercel's page.
