# Blog Categories, Authors and SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A business's blog posts get one category, an author, and search-engine settings with sensible automatic
defaults; client websites list all posts with category filters, have a page per category, and emit schema.org
JSON-LD, Open Graph tags and a sitemap automatically.

**Architecture:** Two new Payload collections (`blogCategories`, `blogAuthors`) owned per business exactly like
`blogPosts` (a `businessId` on every document, every query filtered by it, access denied to Payload's own HTTP API).
`blogPosts` gains `category`, `author`, `metaTitle`, `metaDescription` and `noIndex`. The read-only site API adds
`category`, `author`, `seo` and `updatedAt` to each post **additively** — `categories: string[]` stays, now holding
the one category name — so client sites already deployed keep working. SEO defaults are resolved on the platform, so
every client site gets identical behaviour. The client-site template builds JSON-LD, metadata, category pages and the
sitemap from the API data and its own origin.

**Tech Stack:** Next.js 16 (App Router), Payload 3 (Local API, `@payloadcms/db-postgres`), TypeScript strict,
Vitest, Tailwind 4.

## Decisions (confirmed with the user 2026-09-24)

- **One category per post.** No tags.
- Categories are a list the business manages: pick from a dropdown in the post editor, add a new one inline, rename
  or delete on a "Categories & authors" page. Deleting a category leaves its posts uncategorised (Payload's FK is
  `ON DELETE SET NULL`).
- **Author:** name + optional one-line bio, managed the same way. **No author photo** — blog media is ON HOLD
  (cover uploads fail in prod and `/content-media/*` is not public; user decides Monday 2026-09-28).
- **SEO fields**, all optional, in a collapsed "Search engine settings" section:
  - meta title → defaults to the post title (max 70)
  - meta description → defaults to the excerpt, else the first ~160 characters of the body (max 160)
  - "Hide from search engines" (`noIndex`) → default off
  - Share image = the cover image (no separate upload, same media hold).
- **Schema is automatic**, never a setting: `BlogPosting` + `BreadcrumbList` JSON-LD on every post page.
- A category renamed gets a new address (slug follows the name). Acceptable while blogs are young.
- `category` becomes a reserved post slug (client sites own `/blog/category/...`), alongside `preview`.

/**
 * Web addresses for blog posts and categories. Pure, so both the post and category actions share one definition
 * and it is tested without Payload.
 */

/** "Café Specials & Offers!" → "cafe-specials-offers". Empty when nothing usable is left. */
export function slugify(text: string): string {
  return text
    .normalize("NFKD")
    .replace(/[\u0300-\u036f]/g, "")
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "");
}

/** `base`, or the first of `base-2`, `base-3`, … not in `taken`. */
export function firstUnusedSlug(base: string, taken: ReadonlySet<string>): string {
  if (!taken.has(base)) return base;
  let suffix = 2;
  while (taken.has(`${base}-${suffix}`)) suffix += 1;
  return `${base}-${suffix}`;
}
```

/** Text nodes' text; every other node is its children's text. Blocks are separated by a space. */
function plainTextOf(node: LexicalNode): string {
  if (node.type === "text") return typeof node.text === "string" ? node.text : "";
  return asNodes(node.children).map(plainTextOf).join(node.type === "root" || node.type === "list" ? " " : "");
}

/**
 * The post's words with no markup, whitespace collapsed — the source of a default search description
 * (lib/blog-seo.ts). Uses the same tree walk as the HTML so it can never see text the HTML leaves out.
 */
export function lexicalToPlainText(document: unknown): string {
  if (document === null || typeof document !== "object") return "";
  const root = (document as { readonly root?: LexicalNode }).root;
  if (root === undefined || root === null) return "";
  return plainTextOf({ ...root, type: "root" }).replace(/\s+/g, " ").trim();
}
```

```ts
/**
 * A post's search-engine title and description: what the customer typed, or a sensible default. Resolved on the
 * platform (lib/site-post.ts) so every client site shows the same thing without its own copy of these rules.
 */

/** Roughly what Google shows before cutting a title off. The editor warns past it; nothing is truncated. */
export const META_TITLE_MAX_LENGTH = 70;
/** Roughly what Google shows of a description. Typed descriptions are capped at this in the action. */
export const META_DESCRIPTION_MAX_LENGTH = 160;

export interface SeoSource {
  readonly title: string;
  readonly excerpt: string | null;
  /** lexicalToPlainText of the body. */
  readonly bodyText: string;
  readonly metaTitle: string | null;
  readonly metaDescription: string | null;
  readonly noIndex: boolean;
}

export interface ResolvedSeo {
  readonly title: string;
  readonly description: string | null;
  readonly noIndex: boolean;
}

/** `text` whole, or cut at the last space that fits `max` (ellipsis included). */
export function truncateAtWord(text: string, max: number): string {
  if (text.length <= max) return text;
  const room = text.slice(0, max - 1);
  const lastSpace = room.lastIndexOf(" ");
  return `${(lastSpace > 0 ? room.slice(0, lastSpace) : room).trimEnd()}…`;
}

function present(value: string | null): string | null {
  const trimmed = value?.trim() ?? "";
  return trimmed === "" ? null : trimmed;
}

export function resolveSeo(source: SeoSource): ResolvedSeo {
  const bodyText = present(source.bodyText);
  return {
    title: present(source.metaTitle) ?? source.title,
    description:
      present(source.metaDescription) ??
      present(source.excerpt) ??
      (bodyText === null ? null : truncateAtWord(bodyText, META_DESCRIPTION_MAX_LENGTH)),
    noIndex: source.noIndex,
  };
}
```

import { lexicalToHtml, lexicalToPlainText } from "./blog-html";
import { resolveSeo, type ResolvedSeo } from "./blog-seo";

/**
 * The post shape `/api/site/posts` and its preview endpoint send to client websites.
 *
 * Changes are ADDITIVE ONLY. Client sites are independently deployed repositories; a removed or retyped field breaks
 * every one of them at once. `categories` is kept for sites written before `category` existed.
 */
export interface SitePostCategory {
  readonly slug: string;
  readonly name: string;
}

export interface SitePostAuthor {
  readonly name: string;
  readonly bio: string | null;
}

export interface SitePost {
  readonly slug: string;
  readonly title: string;
  readonly excerpt: string | null;
  readonly publishedAt: string | null;
  /** Last edit, for sitemaps and schema.org `dateModified`. */
  readonly updatedAt: string | null;
  /** The post body as HTML, already escaped and with unsafe link schemes stripped. See lib/blog-html.ts. */
  readonly html: string;
  /** Absolute path on this platform, or null. Client sites prefix it with the platform origin. */
  readonly coverImagePath: string | null;
  /** The post's category name, as a list of zero or one. Kept for client sites that predate `category`. */
  readonly categories: readonly string[];
  readonly category: SitePostCategory | null;
  readonly author: SitePostAuthor | null;
  /** Search title/description with defaults already applied (lib/blog-seo.ts). */
  readonly seo: ResolvedSeo;
}

/** A Payload blogPosts document read at depth 1, typed only as far as this mapping trusts it. */
export interface RawSitePost {
  readonly slug?: unknown;
  readonly title?: unknown;
  readonly excerpt?: unknown;
  readonly publishedAt?: unknown;
  readonly updatedAt?: unknown;
  readonly body?: unknown;
  readonly coverImage?: unknown;
  readonly category?: unknown;
  readonly author?: unknown;
  readonly metaTitle?: unknown;
  readonly metaDescription?: unknown;
  readonly noIndex?: unknown;
}

function record(value: unknown): Record<string, unknown> | null {
  return typeof value === "object" && value !== null && !Array.isArray(value) ? (value as Record<string, unknown>) : null;
}

function text(value: unknown): string | null {
  return typeof value === "string" && value.trim() !== "" ? value : null;
}

function coverImagePath(cover: unknown): string | null {
  const resolved = record(cover);
  return resolved === null ? null : `/content-media/${String(resolved.id)}`;
}

/** Null unless the relation was resolved (depth ≥ 1) to a document carrying both fields. */
function categoryOf(value: unknown): SitePostCategory | null {
  const doc = record(value);
  const name = text(doc?.name);
  const slug = text(doc?.slug);
  return name === null || slug === null ? null : { slug, name };
}

function authorOf(value: unknown): SitePostAuthor | null {
  const doc = record(value);
  const name = text(doc?.name);
  return name === null ? null : { name, bio: text(doc?.bio) };
}

export function toSitePost(post: RawSitePost): SitePost {
  const title = typeof post.title === "string" ? post.title : "";
  const excerpt = text(post.excerpt);
  const category = categoryOf(post.category);
  return {
    slug: typeof post.slug === "string" ? post.slug : "",
    title,
    excerpt,
    publishedAt: text(post.publishedAt),
    updatedAt: text(post.updatedAt),
    html: lexicalToHtml(post.body),
    coverImagePath: coverImagePath(post.coverImage),
    categories: category === null ? [] : [category.name],
    category,
    author: authorOf(post.author),
    seo: resolveSeo({
      title,
      excerpt,
      bodyText: lexicalToPlainText(post.body),
      metaTitle: text(post.metaTitle),
      metaDescription: text(post.metaDescription),
      noIndex: post.noIndex === true,
    }),
  };
}

interface RawTaxonomyDoc {
  readonly id: string | number;
  readonly businessId?: unknown;
  readonly name?: unknown;
  readonly slug?: unknown;
  readonly bio?: unknown;
}

/** Same discipline as BlogPostOwnershipError: a real id belonging to another business. */
export class BlogTaxonomyOwnershipError extends Error {
  constructor(collection: TaxonomyCollection, id: string) {
    super(`${collection} ${id} does not belong to this business.`);
    this.name = "BlogTaxonomyOwnershipError";
  }

/** Confirms a client-supplied category/author id belongs to `businessId`. Payload's NotFound propagates as-is. */
export async function requireOwnedTaxonomyDoc(
  payload: Payload,
  collection: TaxonomyCollection,
  id: string,
  businessId: string,
): Promise<RawTaxonomyDoc> {
  const doc = (await payload.findByID({ collection, id, depth: 0, overrideAccess: true })) as unknown as RawTaxonomyDoc;
  if (doc.businessId !== businessId) throw new BlogTaxonomyOwnershipError(collection, id);
  return doc;
}

/** Every doc of one taxonomy collection for a business, by name. Filtered again in memory so a query-layer mistake
 * can never leak another business's names. */
export async function listTaxonomyDocs(
  payload: Payload,
  collection: TaxonomyCollection,
  businessId: string,
): Promise<readonly RawTaxonomyDoc[]> {
  const result = await payload.find({
    collection,
    where: { businessId: { equals: businessId } },
    sort: "name",
    depth: 0,
    pagination: false,
    overrideAccess: true,
  });
  return (result.docs as unknown as readonly RawTaxonomyDoc[]).filter((doc) => doc.businessId === businessId);
}

"use server";

import { refresh } from "next/cache";
import { getPayload, NotFound, type Payload } from "payload";
import { cleanLine } from "@brandbasket/shared/lib/validation/text";
import config from "@/payload.config";
import { firstUnusedSlug, slugify } from "@/lib/blog-slug";
import { paidCustomerOrNull } from "@/lib/server/blog-access";
import { BLOG_PAYMENT_REQUIRED_MESSAGE } from "@/lib/server/blog";
import {
  BlogTaxonomyOwnershipError,
  listTaxonomyDocs,
  requireOwnedTaxonomyDoc,
  type TaxonomyCollection,
} from "@/lib/server/blog-taxonomy";

/** What the editor's inline "New category/author" needs back to select the new entry. */
export interface TaxonomyOption {
  readonly id: string;
  readonly name: string;
}

export type TaxonomyResult =
  | { readonly ok: true; readonly value: TaxonomyOption }
  | { readonly ok: false; readonly message: string };

export type TaxonomyDeleteResult = { readonly ok: true } | { readonly ok: false; readonly message: string };

const MAX_NAME_LENGTH = 60;
const MAX_BIO_LENGTH = 160;
const PAYMENT_REQUIRED = { ok: false, message: BLOG_PAYMENT_REQUIRED_MESSAGE } as const;
const GONE = { ok: false, message: "That no longer exists. Reload the page." } as const;

function sameName(a: unknown, b: string): boolean {
  return typeof a === "string" && a.toLocaleLowerCase() === b.toLocaleLowerCase();
}

/** Runs `write`, turning "not this business's" / "doesn't exist" into GONE. */
async function owned<T>(write: () => Promise<T>): Promise<T | typeof GONE> {
  try {
    return await write();
  } catch (error) {
    if (error instanceof BlogTaxonomyOwnershipError || error instanceof NotFound) return GONE;
    throw error;
  }
}

/** A free category address in this business, ignoring `exceptId` (the category being renamed). */
async function freeCategorySlug(payload: Payload, businessId: string, name: string, exceptId?: string): Promise<string> {
  const docs = await listTaxonomyDocs(payload, "blogCategories", businessId);
  const taken = new Set(
    docs.filter((doc) => String(doc.id) !== exceptId).map((doc) => doc.slug).filter((s): s is string => typeof s === "string"),
  );
  return firstUnusedSlug(slugify(name), taken);
}

/**
 * Creates a category, or returns the existing one with the same name (any case) — so the editor's inline "New
 * category" never makes duplicates. The business id comes only from the paid session.
 */
export async function createBlogCategoryAction(rawName: string): Promise<TaxonomyResult> {
  const access = await paidCustomerOrNull();
  if (access === null) return PAYMENT_REQUIRED;
  const businessId = access.tenant.businessId;

  const name = cleanLine(rawName).slice(0, MAX_NAME_LENGTH);
  if (name === "") return { ok: false, message: "Give the category a name." };
  if (slugify(name) === "") return { ok: false, message: "Use some letters or numbers in the name." };

  const payload = await getPayload({ config });
  const existing = (await listTaxonomyDocs(payload, "blogCategories", businessId)).find((doc) => sameName(doc.name, name));
  if (existing !== undefined) return { ok: true, value: { id: String(existing.id), name: String(existing.name) } };

  const created = await payload.create({
    collection: "blogCategories",
    data: { businessId, name, slug: await freeCategorySlug(payload, businessId, name) },
    overrideAccess: true,
  });
  refresh();
  return { ok: true, value: { id: String(created.id), name } };
}

export async function renameBlogCategoryAction(id: string, rawName: string): Promise<TaxonomyResult> {
  const access = await paidCustomerOrNull();
  if (access === null) return PAYMENT_REQUIRED;
  const businessId = access.tenant.businessId;

  const name = cleanLine(rawName).slice(0, MAX_NAME_LENGTH);
  if (name === "") return { ok: false, message: "Give the category a name." };
  if (slugify(name) === "") return { ok: false, message: "Use some letters or numbers in the name." };

  const payload = await getPayload({ config });
  return owned(async () => {
    await requireOwnedTaxonomyDoc(payload, "blogCategories", id, businessId);
    const clash = (await listTaxonomyDocs(payload, "blogCategories", businessId)).find(
      (doc) => String(doc.id) !== id && sameName(doc.name, name),
    );
    if (clash !== undefined) return { ok: false, message: `You already have a category called ${String(clash.name)}.` } as const;
    await payload.update({
      collection: "blogCategories",
      id,
      data: { name, slug: await freeCategorySlug(payload, businessId, name, id) },
      overrideAccess: true,
    });
    refresh();
    return { ok: true, value: { id, name } } as const;
  });
}

async function deleteOwned(collection: TaxonomyCollection, id: string): Promise<TaxonomyDeleteResult> {
  const access = await paidCustomerOrNull();
  if (access === null) return PAYMENT_REQUIRED;
  const payload = await getPayload({ config });
  return owned(async () => {
    await requireOwnedTaxonomyDoc(payload, collection, id, access.tenant.businessId);
    // Posts pointing at it become uncategorised / authorless: the FK is ON DELETE SET NULL.
    await payload.delete({ collection, id, overrideAccess: true });
    refresh();
    return { ok: true } as const;
  });
}

export async function deleteBlogCategoryAction(id: string): Promise<TaxonomyDeleteResult> {
  return deleteOwned("blogCategories", id);
}

function cleanAuthor(rawName: string, rawBio: string): { name: string; bio: string | null } | { error: string } {
  const name = cleanLine(rawName).slice(0, MAX_NAME_LENGTH);
  if (name === "") return { error: "Give the author a name." };
  const bio = cleanLine(rawBio).slice(0, MAX_BIO_LENGTH);
  return { name, bio: bio === "" ? null : bio };
}

export async function createBlogAuthorAction(rawName: string, rawBio: string): Promise<TaxonomyResult> {
  const access = await paidCustomerOrNull();
  if (access === null) return PAYMENT_REQUIRED;
  const cleaned = cleanAuthor(rawName, rawBio);
  if ("error" in cleaned) return { ok: false, message: cleaned.error };

  const payload = await getPayload({ config });
  const created = await payload.create({
    collection: "blogAuthors",
    data: { businessId: access.tenant.businessId, ...cleaned },
    overrideAccess: true,
  });
  refresh();
  return { ok: true, value: { id: String(created.id), name: cleaned.name } };
}

export async function updateBlogAuthorAction(id: string, rawName: string, rawBio: string): Promise<TaxonomyResult> {
  const access = await paidCustomerOrNull();
  if (access === null) return PAYMENT_REQUIRED;
  const cleaned = cleanAuthor(rawName, rawBio);
  if ("error" in cleaned) return { ok: false, message: cleaned.error };

  const payload = await getPayload({ config });
  return owned(async () => {
    await requireOwnedTaxonomyDoc(payload, "blogAuthors", id, access.tenant.businessId);
    await payload.update({ collection: "blogAuthors", id, data: cleaned, overrideAccess: true });
    refresh();
    return { ok: true, value: { id, name: cleaned.name } } as const;
  });
}

export async function deleteBlogAuthorAction(id: string): Promise<TaxonomyDeleteResult> {
  return deleteOwned("blogAuthors", id);
}

interface TaxonomyPickerProps {
  /** Form field name; the select submits the chosen id, or "" for none. */
  readonly name: string;
  readonly label: string;
  readonly noneLabel: string;
  /** "New category", "New author". */
  readonly addLabel: string;
  readonly options: readonly TaxonomyOption[];
  readonly initialId: string | null;

}

const FIELD =
  "mt-1.5 block w-full rounded-control border border-line bg-paper px-3 py-2.5 text-base text-ink transition-colors duration-300 ease-calm focus:border-accent";

/**
 * A dropdown of the business's own categories (or authors) with an inline "New …" that creates one and selects it,
 * so writing a post never means leaving the editor. The new entry is saved at once; the post itself still needs Save.
 * The inline input has no `name`, so it is never submitted with the post form, and Enter adds rather than submits.
 */
export function TaxonomyPicker({ name, label, noneLabel, addLabel, options, initialId, create }: TaxonomyPickerProps): ReactElement {
  const [choices, setChoices] = useState<readonly TaxonomyOption[]>(options);
  const [selected, setSelected] = useState<string>(initialId ?? "");
  const [adding, setAdding] = useState(false);
  const [draft, setDraft] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [isPending, startTransition] = useTransition();

  function add(): void {
    startTransition(async () => {
      const result = await create(draft);
      if (!result.ok) {
        setError(result.message);
        return;
      }
      setChoices((current) =>
        current.some((c) => c.id === result.value.id)
          ? current
          : [...current, result.value].sort((a, b) => a.name.localeCompare(b.name)),
      );
      setSelected(result.value.id);
      setDraft("");
      setError(null);
      setAdding(false);
    });
  }

  return (
    <div>
      <label htmlFor={name} className="block text-sm font-medium">{label}</label>
      <select id={name} name={name} value={selected} onChange={(e) => setSelected(e.target.value)} className={FIELD}>
        <option value="">{noneLabel}</option>
        {choices.map((choice) => (
          <option key={choice.id} value={choice.id}>{choice.name}</option>
        ))}
      </select>
      {adding ? (
        <div className="mt-2 flex flex-wrap items-center gap-2">
          <input
            aria-label={addLabel}
            value={draft}
            autoFocus
            maxLength={60}
            onChange={(e) => setDraft(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === "Enter") {
                e.preventDefault();
                add();

    readonly name: string;

  }

  /** Categories that have at least one published post — an empty category never gets a page or a chip. */
  export function categoriesOf(posts: readonly BlogPost[]): readonly CategorySummary[] {
    const bySlug = new Map<string, CategorySummary>();
    for (const { category } of posts) {
      if (category === null) continue;
      const seen = bySlug.get(category.slug);
      bySlug.set(category.slug, { slug: category.slug, name: category.name, count: (seen?.count ?? 0) + 1 });
    }
    return [...bySlug.values()].sort((a, b) => a.name.localeCompare(b.name));
  }

  export function postsInCategory(posts: readonly BlogPost[], slug: string): readonly BlogPost[] {
    return posts.filter((post) => post.category?.slug === slug);
  }

  export function relatedPosts(posts: readonly BlogPost[], current: BlogPost, limit: number): readonly BlogPost[] {
    if (current.category === null) return [];
    return postsInCategory(posts, current.category.slug).filter((p) => p.slug !== current.slug).slice(0, limit);

  import type { BlogPost } from "./blog-model";

  /**
   * schema.org data for blog pages, built automatically from the post — customers never see or set any of this.
   * Pure and absolute-URL-only, because search engines ignore relative URLs in JSON-LD.
   */
  export interface SchemaContext {
    readonly siteUrl: string;
    readonly businessName: string;
  }

  type JsonLd = Record<string, unknown>;

  export function postUrl(siteUrl: string, slug: string): string {
    return `${siteUrl}/blog/${encodeURIComponent(slug)}`;
  }

  export function categoryUrl(siteUrl: string, slug: string): string {
    return `${siteUrl}/blog/category/${encodeURIComponent(slug)}`;
  }

  export function blogPostingJsonLd(post: BlogPost, { siteUrl, businessName }: SchemaContext): JsonLd {
    const url = postUrl(siteUrl, post.slug);
    const publisher = { "@type": "Organization", name: businessName, url: siteUrl };
    return {
      "@context": "https://schema.org",
      "@type": "BlogPosting",
      headline: post.seo.title.slice(0, 110), // Google's headline limit
      ...(post.seo.description === null ? {} : { description: post.seo.description }),
      url,
      mainEntityOfPage: url,
      ...(post.publishedAt === null ? {} : { datePublished: post.publishedAt }),
      ...(post.updatedAt ?? post.publishedAt) === null ? {} : { dateModified: post.updatedAt ?? post.publishedAt },
      author: post.author === null ? publisher : { "@type": "Person", name: post.author.name },
      publisher,
      ...(post.coverImageUrl === null ? {} : { image: [post.coverImageUrl] }),
      ...(post.category === null ? {} : { articleSection: post.category.name }),
    };
  }

  import { categoriesOf } from "@/lib/blog-categories";
  import { categoryUrl, postUrl } from "@/lib/blog-schema";
  import { getBlog } from "@/lib/fynix-blog";

  export const revalidate = 3600;

  /** Home, the blog, every category with posts, and every post not hidden from search engines. */
  export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
    const origin = siteUrl();
    const pages: MetadataRoute.Sitemap = [{ url: `${origin}/` }, { url: `${origin}/blog` }];
    const blog = await getBlog();
    if (blog.kind !== "ok") return pages; // the platform is down: still list the static pages

      ...pages,

          lastModified: post.updatedAt ?? post.publishedAt ?? undefined,
