Branch `cr/01-console-patterns`, stacked on `docs/console-rulings` (PR #226). The PR targets `development`, so it shows #226's commit until that merges.

## What was built (`packages/shared/src/ui/patterns/`)

New patterns, all exported from `index.ts`: `data-table.tsx` (with `data-table-logic.ts`), `filter-bar.tsx`, `side-panel.tsx` (with `useUrlParam`), `command-bar.tsx`, `toast.tsx` (module store, `ToastRegion`, `useToast`), `bulk-bar.tsx`, `row-actions.tsx`, `inline-edit.tsx`, `shortcut-help.tsx`, `use-shortcuts.ts` (registry, sequence matcher, hook).

Support files: `use-layer.ts` (one Esc stack, focus trap, focus return), `modal-dialog.tsx` (native `<dialog>`), `confirm-copy.tsx` (`ConfirmCopy`, `ConfirmCopyDialog`, `useConfirmRun`), `pattern-icons.tsx`, `console-patterns-demo.tsx` (live specimen), `dom-test-utils.ts` (test helper, not exported).

Other files: `apps/admin/app/design-system/page.tsx` and `apps/customer/src/app/design-system/patterns-showcase.tsx` show the live demo; `packages/shared/src/styles/theme.css` and `apps/customer/src/styles/globals.css` gain tokens and utilities (below).

No existing screen adopts a pattern. `table.ts`, `filter-pills`, `global-search`, the shared `ConfirmDialog` and the console `confirm-dialog` are untouched. `ToastRegion` is not mounted in any layout.

## Token and CSS additions (note for CR-00)

Additive in both the console bridge and the customer globals: `--color-field` (#cfcbc2, input border), `--color-row-hover` (#faf9f6), `--color-gold-soft` (#fbf4ea, selected row wash), and `motion-rise` and `motion-pop` utilities, both switched off under `prefers-reduced-motion`. Patterns use no hex or `rgb(` values. Scrim is `bg-ink/40`.

## Deliberate changes and deviations from the notes

- Selected and open rows use the gold wash and a 3px gold marker (the cursor is a 2px ink marker). This is the ruled change from the ink marker; it lives in `data-table.tsx`, so the admin `TR_SELECTED` is unchanged until pages adopt DataTable.
- `BulkBar` takes `ids` (not `count`), plus `onSettled(failedIds)` so the list keeps failed rows selected, and per action `doneMessage` and `partialMessage`. There is no money flag by design.
- `SidePanel` has no `urlParam` prop; the exported `useUrlParam("open")` owns `?open=` with `history.replaceState`.
- `RowActions` takes `busyLabel`, `confirm` on the verb, and controlled `open`. `DataTable` takes `rowGroup`, `density` (`compact` is the 36px row for Invoices and Access log only, ruling 20) and keeps 44px otherwise.
- Rulings applied: 17 (errors persist, plain 4s, Undo 10s), 19 (right click only on the dots column), 7 (`u`, `g o`, `g s`, Shift extend and Ctrl A; `e` everywhere), 18 (44px buttons under 860px).
- Dialogs are native `<dialog>.showModal()` with an added Tab fallback and focus return. The wide SidePanel is a complementary region; below 1100px it is a dialog with scrim and a focus trap.
- Shortcut registry: `?` via `helpShortcut`, `u` via `TOAST_UNDO_SHORTCUT` (registered by `ToastRegion`; pass the same object to `ShortcutHelp` only).
