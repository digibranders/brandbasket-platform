# CR-02: shell and information architecture

Branch `cr/02-shell-rail`, from `origin/development` (which holds N1, CR-01, CR-04 and CR-08). Not verified in a browser.

## What changed

- `lib/console-rail.ts`: six items (Today, Clients, Inbox, Money, Compliance, System), the same for everyone. `needs`, `railFor(role)`, `ROLE_LABELS` and the `quiet` tone are gone. `CONSOLE_RAIL_LINKS` replaces `railFor`; `tabsFor(page)` drops the role. `RAIL_ALIASES` is now only `/outbox` to System. Count keys `projects` and `calls` are removed (no item shows them).
- Regrouping, URLs unchanged: Inbox holds `/support`, `/leads`, `/reports`. Money holds `/payments`, `/invoices`, `/pricing`, `/coupons`, `/affiliates`, `/ad-results` (label Acquisition). Compliance holds `/privacy-requests`, `/breaches`, `/leaving`, `/access-log`. System holds `/deliveries`, `/support/errors`, `/settings`, `/staff` (label Access). Clients holds `/clients`.
- `components/console/top-bar.tsx` (new): command bar field with the ⌘K hint (owns the shortcut) and the N1 bell. `rail.tsx` loses search, bell and role; `phone-bar.tsx` keeps its bell and search; `rail-nav.tsx` footer reads "Signed in" instead of a role; `rail-icon.tsx` has the six icons; `console-shell.tsx` mounts the top bar.
- `lib/server/rail-counts.ts`: stops reading late projects and today's calls. Failed reads still leave that count off; a loading or failed count shows nothing.
- `components/console/section-tabs.tsx`: `role` prop kept as an ignored optional prop so the 17 pages that pass it need no edit.
- `apps/admin/DESIGN.md` Shell bullets updated. `(protected)/layout.tsx` untouched.
