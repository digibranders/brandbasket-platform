# WP-04 Implementation Report: Refund Flow

Package: WP-04 Refund flow (Release 1 priority 11, step 13.4)
Branch: `wp/04-refund-flow`
Date: 2026-11-14

## 1. Overview and What Changed

This package implements an end to end refund flow for staff in the admin console. A refund actually calls the payment provider, records the refund, issues a GST compliant credit note linked to the invoice, cancels related affiliate earnings, emails the customer, and writes to the access log.

### Key Changes
1. **Provider Refund Integration (`packages/billing`)**:
   - Extended `BillingProvider` interface with `refundPayment(paymentId, amountCents, reason)`.
   - Implemented `fake-provider.ts` refund support (in memory successful return with generated refund id).
   - Implemented Razorpay SDK adapter `createRefund` and provider `refundPayment` calling Razorpay payments API.
2. **Statutory Credit Note Generation (`packages/billing/src/credit-note.ts`, `packages/shared/src/server/tax-invoicing.ts`)**:
   - Created `credit_notes` schema in `packages/db/src/schema/tax-invoices.ts` and migration `0226_credit_notes.sql`.
   - Added sequential numbering format `CN/YY-YY/XXXXXX` per Indian GST rules, matching invoice financial year rules.
   - Calculates exact proportional GST reversals (CGST, SGST, IGST) based on the original invoice lines and supply type.
   - Idempotent: checks for existing credit note before creating a new one.
3. **Refund Orchestration (`packages/shared/src/server/payment-refund.ts`)**:
   - `executePaymentRefund`: atomic transaction locking payment and business.
   - Checks idempotency: if already refunded for full amount, returns existing record.
   - Calls provider first. If provider call fails, rolls back transaction and marks nothing in database.
   - Updates payment record with refunded amount and status.
   - Cancels any pending or approved affiliate earnings for that payment.
   - Generates and persists credit note.
   - Logs staff access event and sends customer refund notification email.
4. **Staff Console UI (`apps/admin`)**:
   - Added staff action "Refund" with modal dialog for amount (full or partial) and reason.
   - Clearly labelled secondary action: "Record a refund made outside BrandBasket" for offline/manual refunds without calling the gateway.
   - Displays refund status, refund amount, and credit note badge on client payments list and billing tab.
5. **Customer Refund Email (`packages/email/src/templates/payment-refunded.ts`)**:
   - Sends confirmation email to customer stating amount refunded, original payment, credit note number, and 5 to 10 business days settlement timeline.
   - Strictly zero em or en dashes.
