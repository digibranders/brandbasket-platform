## What changed

- Ctrl K or Cmd K (pattern) and `/` open the bar. `/` is ignored while typing in a field or when a dialog is open.
- Groups: Recent, Go to, Actions, then the six search kinds. `>` shows actions only, `#` shows request references only (the server result is filtered to requests).
- Search is the same `POST /search`, so the route still guards, normalises and writes `search.run` to the access log exactly as before. Nothing about what is searchable changed.
- Recent is in `localStorage` only: link, title and subtitle of a search result the staff opened, five at most, newest first. Read back through zod, and links must start with a single `/`. The server stores and returns nothing for it. Go to and Actions are not recorded.
- Actions (each opens an existing route, which keeps its own guard): Add enquiry (`/leads/new`), New request (`/support/new`), Export payments (opens `/payments`, where the logged export lives), Open privacy requests (`/privacy-requests`).
- States: idle (Recent, Go to, Actions), loading (skeleton rows), results, empty (message plus Add enquiry and New request), error (message and Try again, Go to and Actions stay usable).
- One staff account: no role filtering of the menu. Pages and routes guard themselves.
- Only the rail's instance listens for keys. The phone bar's instance mounts the bar only while open, so shortcuts never open two bars.

## Open questions

1. `/` is also the Today filter focus key in the mock. If CR-03 binds `/` on Today, one of them must change. This package binds `/` everywhere.
2. Go to is built from `CONSOLE_RAIL` as it is today (eight items). It follows CR-02 automatically when the six item rail lands. No `g t` style hints are shown because those shortcuts are not registered yet.
3. Export payments only opens Payments, because the CSV export needs a month. Say if it should open a month picker instead.
4. In the empty state, Enter runs the first offered action (Add enquiry). Say if Enter should do nothing there.
5. On a phone-width screen with a keyboard, Ctrl K opens the rail instance, which is hidden below `lg` (same as before this change).
