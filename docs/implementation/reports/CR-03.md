# CR-03: Today, the unified work queue

Branch `cr/03-today`, from `origin/cr/02-shell-rail` (PR #232, not yet merged), so this PR also carries CR-02's commit until #232 merges. Not verified in a browser.

## What changed

- `lib/today-queue.ts`: five new kinds (`privacy`, `breach`, `closure`, `report`, `preview_silent`) with their input shapes; groups are now Late, Due today, Waiting on someone, Upcoming (`groupTodayQueue`); filter model (`TODAY_FILTERS`, `matchesTodayFilter`, `todayFilterCounts`, `filtersFailedBy`); `rowClock` (privacy and breach rows use `requestClock` and `breachClock`, red only when late); `NEXT_STEPS`; `clientIdOf`; the kickoff verb is "Call completed" and the kickoff row href is `/`.
- `lib/today-sources.ts` (new): pure builders for the new rows from reads that already exist.
- `lib/server/today.ts`: reads `listOpenPrivacyRequests`, `listBreaches`, `listOpenClosures` (only with the `oversight` capability, new 4th argument, default false), `listReportsForReview`, `countSupportQueues` (Open requests tile) and `listSetupCallsForStaff` (Calls card). Each is `guarded`, so a failed source is named. `activeClientsCount` is gone. Silent previews come from the client list already read.
- `app/(protected)/page.tsx`: four tiles (Late, Due today, On track, Open requests), per-source failure notice, the workspace, the Calls card and Systems.
- `components/today/today-workspace.tsx` (new, client): sticky `FilterBar` with counts (a failed source shows "?"), the Late rows as one focal card (gold top edge, hero shadow) and the other bands in a second `DataTable`, 44px rows (icon tile, title and one line, Mono clock, one verb, `RowActions` with Open client), `SidePanel` at `?open=<key>` (clock, next step, same primary, Open client), `BulkBar`, `ShortcutHelp`, shortcuts `j k Enter e x /` (the table and filter bar own them) and `g t g c g i g m g o g s ?`, empty state, error notice. A kickoff row opens the kickoff prompt, not the panel.
- `components/today/kickoff-prompt.tsx`: now one controlled prompt (the three existing actions, notes kept on failure) opened from the row. `needs-someone.tsx` deleted. `calls-today.tsx` is the Calls card (Today, Coming up, Last 7 days).
- `app/(protected)/today-actions.ts` (new): `resendAllFailedFromTodayAction`, the same call, limits, access log and activity record as the Deliveries page's `resendAllFailedAction`, but it returns the counts instead of redirecting (a redirect cannot feed the bulk bar). No change to the existing action.
- CR-02 follow-ups: kickoff row, the three notification copy files (`notification-copy-bell`, `-email`, `-push`) and `kickoff-actions.ts` now point at `/` instead of `/calls`. `calls/kickoff-wrap-up.tsx` and its test deleted (only its own test imported it). N2's popup mount in `(protected)/layout.tsx` is untouched (it is not mounted on this base).
- `lib/server/rail-counts.ts`: passes the oversight capability as the third argument to `countTodayItems` so the rail count matches the list.

## Kinds built versus deferred

| Kind | Status | Source |
|---|---|---|
| Privacy request | Built | `listOpenPrivacyRequests`, due date, request clock |
| Breach | Built | `listBreaches`, CERT-In deadline first then Board, breach clock |
| Closure erasing soon | Built | `listOpenClosures`, within 7 days (my choice, say if wrong) |
| Report to review | Built, one row | `listReportsForReview` drafts and approved, due end of the 5th |
| Preview sent, silent 5 days | Built | client list, status `preview`, `previewSentAt`; no clock, sits in Waiting on someone |
| Service ending (cancel pending) | Deferred | needs a cross-business query of `end_requested_at` (new read) |
| Social alert | Deferred | N7 |
| Failed email after retries, missing Teams address | Deferred | N3, N6 |
| Timer not running | Deferred | N6 / CD-20 |
| Side panel "what the customer sees" and "last message" | Deferred | needs per-kind reads; the panel shows the clock and the next step only |

Closure rows use the client name from the client list; an account missing from it shows "An account".

## Open questions

1. The Late card and the second table are two `DataTable`s, so `j k` stop at the end of each; the side panel's `j k` steps across both.
2. Rows with no client (delivery, privacy, breach, reports) have an empty overflow menu (the dots are disabled). Say if you want "Open" repeated there.
3. Go-to shortcuts (`g t` and the rest) are registered on Today only; no global registry exists in the shell yet.
4. Preview-silent and customer-wait rows (sign-ups) sit in Waiting on someone and never turn red as silent; a sign-up still goes to Late once its 2 day clock runs out.
5. Null-clock rows (failed deliveries, Google rows without a date) fall in Upcoming, as before.
