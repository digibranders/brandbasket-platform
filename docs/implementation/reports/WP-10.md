# WP-10: Sign-up, Questions, and Unpaid State Report

## 1. What Changed
- **Unpaid Customer Navigation & Freedom**:
  - Updated `apps/customer/src/lib/guard-rules.ts` and `apps/customer/src/app/(app)/layout.tsx` so unpaid customers can navigate freely to `/help`, `/settings`, and sign out instead of being locked to `/start`.
- **Dynamic Sign-up Panel Copy**:
  - Updated `apps/customer/src/features/entry/components/auth-art.tsx` and created `apps/customer/src/features/entry/rules/signup-panel.ts`. The side panel heading and steps now strictly reflect the selected services (e.g. Website development steps are displayed only when Website is selected).
- **Abandoned Sign-up Reminders (D21)**:
  - Added `signup_reminder_sent_at` column to `signup_leads` table via migration `0226_signup_reminder_sent_at.sql`.
  - Added query `listAbandonedSignups` and `markSignupReminderSent` in `packages/db/src/queries/leads.ts`.
  - Implemented reminder job in `apps/customer/src/features/entry/server/signup-reminder-job.ts` and route `apps/customer/src/app/api/internal/send-signup-reminders/route.ts` sending exactly one email after 24 hours.
  - Created email template `signupReminderEmail` in `packages/email/src/templates/signup-reminder.ts`.
  - Added abandoned sign-up rows to the Admin Today queue in `apps/admin/lib/server/today.ts`.
  - Created systemd timer and service units in `deploy/vps/systemd/brandbasket-signup-reminder.timer` and `.service`.
- **Sign-up Code Step Refresh Resilience**:
  - Implemented `pending-signup-cookie.ts` to store pending signup state in an encrypted/signed cookie so page refreshes during OTP entry do not reset form progress.
