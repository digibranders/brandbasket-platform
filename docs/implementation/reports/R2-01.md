## 1. What changed for the customer or the team
Created the shared pattern component library in `packages/shared/src/ui/patterns` specified in `RELEASE-2-PLAN.md` Section 5 and `05-PREMIUM-DESIGN-LANGUAGE.md`. Both the customer app and staff console now consume consistent, tested primitives and patterns:
1. `NextActionCard`: Focal element per screen, 20px radius, 3px rattan gold top border, 40px icon tile with gold wash, elevated shadow, clear primary button.
2. `ServiceCard`: 14px radius resting card, 40px icon tile, status chip, secondary action.
3. `StatusTimeline`: Milestone progress indicator with current step emphasis.
4. `Stepper`: Numbered circles with hairline fill, gold active state, sage completed state.
5. `NeedsYourOkList`: Section header with count badge, rows with 40px tile, item age in Mono, review button, and quiet empty state.
6. `ApprovalCard`: Draft preview card with Approve and Request changes actions.
7. `ConfirmDialog`: 20px radius, 28px padding, consequence line in ink-2, destructive red variant with explicit consequences, over warm brown-black scrim.
8. `PromptPopup`: Staff workflow dialog with primary and secondary action slots.
9. `EmptyState`: Peaceful empty state with icon, title, description, and optional action.
10. `ErrorState`: Alert banner with clear recovery action and icon.
11. `Skeleton`: Warm sunken pulse block respecting prefers-reduced-motion.
12. `StatusChip`: Standardized chips for active, next, waiting, idle, and failed states (with live pulsing dot on active only).
13. `StatTile`: 32px mono figures, 13px label, optional trend indicator.
14. `SettingsTabs`: Tab strip with 2px rattan gold active indicator.
15. `PageHeader`: Eyebrow, 36px title, context description, and right-aligned action slot.
16. `PreviewFrame`: 16:10 aspect ratio framed browser preview with URL bar and caption row.
17. `ThumbStrip`: Square picture thumbnails with 12px radius, status ribbon, and gold ring on action items.

Added preview entries in both apps:
- Customer app: `/design-system` renders `PatternsShowcase` showcasing all patterns.
- Staff console: `/design-system` renders staff console pattern showcase.
