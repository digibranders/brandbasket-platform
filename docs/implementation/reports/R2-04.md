## 1. What changed for the customer or the team
Per owner decision 5b in `RELEASE-2-PLAN.md`, Steve designed the Social layouts and those layouts are strictly preserved. This package applies token level visual polish to harmonize Steve's layouts with the Release 2 premium design language without altering any layout, route names, or data behavior:
- Font mappings:
  - Ensured headings, screen headers, and card titles use Red Hat Display (`type-title`, `type-section`).
  - Ensured body text, controls, and labels use Red Hat Text (`type-body`, `type-meta`, `type-label`).
  - Scheduled post counts and figures map to Red Hat Mono (`font-mono`).
- Spacing rhythm:
  - Preserved Steve's grid and sidebar layouts while adhering to the 4px spacing base (`gap-4`, `gap-6`, `gap-8`, padding rhythm).
- Warm brown-black elevations:
  - Replaced cold black drop shadows (`rgb(21 22 26 / 0.5)` and `rgb(21 22 26 / 0.08)`) with the warm brown-black elevation tokens:
    - Resting cards: 1px `#E3E0D9` border with `0 1px 0 rgba(42,28,16,0.03)` warm elevation (shadow-lift token, `LIFT`).
    - Modal dialogs: `0 24px 64px -16px rgba(42,28,16,0.28)` over `rgba(21,22,26,0.40)` scrim (`shadow-dialog`, `backdrop:bg-scrim`) across brand switcher, new post dialog, AI start card, post details, and review workspace dialogs.
    - Drag ghosts: warm elevated shadow (`shadow-pop`).
- Consistent card and control radii:
  - Standardized cards to 14px radius (radius-xl token 0.875rem, radius-lift token 0.875rem, radius-panel token 14px).
  - Standardized dialogs and overlays to 20px radius (radius-2xl token 1.25rem).
  - Standardized buttons and controls to 8px radius (radius-lg token 0.5rem, `DARK_BUTTON_SHAPE` updated to `rounded-lg!`).
  - Chips and pills standardized to full radius pill (`9999px`).
- Theme palette alignment:
  - Aligned legacy social status colors to the brand token constants:
    - Success or active: sage deep (`#2F5A43`) and sage wash (`#E5EFE8`).
    - Warning or attention: rattan deep (`#8A5524`) and rattan wash (`#F4E6D3`).
    - Neutral or info: ink-2 (`#4E5057`) and sunken (`#EEECE7`).
- Settings Social media tab:
  - Replaced legacy `rounded-card` and `shadow-card-ring` with standard `rounded-panel border border-border bg-surface shadow-card`.
  - Number of scheduled posts in impact summary rendered in `font-mono`.
- Clean copy and comments:
  - Cleaned section divider comments in `rules.ts` to guarantee zero em dashes, en dashes, or double hyphens.
- Verified visual restraint:
  - Exactly one focal point per screen.
  - Rattan gold accent used 3 times or fewer per viewport (calendar tab indicator and drop target ring).
