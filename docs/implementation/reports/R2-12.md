On an enquiry's detail page the list becomes a plain table, because the detail panel is the one raised panel there.
- Legacy tokens: `text-ink-soft` became `text-ink-2` and `font-serif` became `font-display` on the client workspace parts, website, requests and calls sections, work section, and the request thread and forms.
- Not changed: enquiry detail, new enquiry, report detail, request thread layout, new request form (already on console tokens and `LIFT`/`Section`).
